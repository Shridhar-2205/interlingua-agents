Token Cost

Every message rides over A2A (HTTP/JSONRPC · SendMessage) — the emerged code travels as an ELP data part (application/vnd.elp+json).

Token = message payload on the wire (word count) — a model-independent proxy for LLM tokens.

Long, repeated messages map to compact symbols; ELP + Theory of Mind grounds each symbol fast, then sends the symbol instead of the sentence — fewer tokens and less context re-sent every turn.
